# 0.1 — Economy placeholders (decision G4 deferred)

**Decision G4: real economy tuning is deferred to WP-7.4.** So intermediate WPs (upgrades, repairs,
reforge, sockets, vendors, respec) have something to cite, this file gives **placeholder** numbers.
None of these are final; WP-7.4 does the one real pass over every faucet and sink and rewrites them,
and `EconomyBalanceTest` (7.4) asserts the documented gold-per-hour band per source.

## Placeholder faucet: gold per hour per band

Band 1 = **300 gold/hr**, doubling each band:

| Band | Gold/hour (target) |
| --- | --- |
| 1 | 300 |
| 2 | 600 |
| 3 | 1,200 |
| 4 | 2,400 |
| 5 | 4,800 |

## Placeholder sinks and spreads

- **Vendor spread:** buy price = **4×** sell price (a vendor buys an item for 1/4 of what it sells the
  same item for). Restock cadence via `TradeRestockBehavior` (WP-7.1).
- **Respec cost:** **10% of lifetime skill-XP value** (WP-5.1c), payable as a consumable item or money.
- **Upgrade cost:** the XP-level curve in [curves-and-tiers](0.1-curves-and-tiers.md)
  (`Σ(2+n)`, rarity-weighted) plus tier materials; money cost per upgrade is set in
  `docs/design/3.3a-*.md`, scaled off the band gold/hour above.
- **Repair cost:** scales with missing durability (WP-3.3b), priced so a full repair is a small
  fraction of an hour's gold at the item's band.
- **Reforge cost:** `RarityRules.reforgeXpCost` (3–40 XP levels by rarity) plus a money cost set in
  `docs/design/3.3c-*.md`.

Every WP that spends or grants currency before WP-7.4 must cite this file and write its own concrete
numbers into its `docs/design/<wp-id>-*.md`, so 7.4 has a single set of documents to reconcile.
